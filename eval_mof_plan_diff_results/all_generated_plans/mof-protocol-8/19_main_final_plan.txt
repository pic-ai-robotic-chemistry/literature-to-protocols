平台可执行实验流程（修订版）

1. 参考合成条件

- 试剂：ZrOCl₂·8H₂O、ZrCl₄、H₄TBAPy、H₄TCPB-Br₂、H₂Me₂-BPDC、H₄CBTB、H₄TPCB、苯甲酸、乙酸、三氟乙酸、DMF、DEF、乙醇、甲醇、S-MBA、PbI₂、PbBr₂、CdI₂、NiBr₂
- 配比/体积：
  - NU-1000：ZrOCl₂·8H₂O（1.5 g）、H₄TBAPy（0.8 g）、苯甲酸（2.0 g）、30 mL DMF
  - NU-600：金属前驱体、H₄TCPB-Br₂、2 mL DEF + 0.8 mL乙酸
  - PCN-700：金属前驱体、H₂Me₂-BPDC、1.5 mL DMF + 0.08 mL三氟乙酸
  - PCN-609/606：金属前驱体、H₄CBTB/H₄TPCB、3 mL DMF + 苯甲酸
  - 其他体积/配比：文献未提供，需平台默认参数
- 反应条件：120°C，24–48小时，密封（高压釜或反应瓶）
- 后处理条件：过滤收集晶体，DMF和乙醇反复洗涤，100°C烘箱干燥10小时，部分样品需真空或火焰封管活化（120°C，1个月），部分样品需室温胺修饰（数天）
- 最终分散条件：文献未提供，需平台默认参数

2. 平台适配前提

- 溶剂热反应需密封，平台选用耐热高压反应瓶，兼容120°C、30 mL及更大体积。
- 火焰封管活化无法由平台直接实现，采用耐热密封容器+高温烘箱/管式炉替代。
- 洗涤采用纯化/离心+超声分散动作链。
- 胺修饰步骤需长时间室温浸泡，平台仅能实现前期加液及分装，长期浸泡需人工或平台长时托管。
- 电化学测试、PL、CPL等表征不在本次合成及后处理平台流程内。
- 离心条件、搅拌速率等未提供，需平台默认参数。

3. 标准流程链

物料站_303物料-耐热 → 固体进样器_单通道固体称量_v1 → 液体进样站_移液平台5ml_V1 → 磁力搅拌_加热磁力搅拌工作站_V1 → 反应器_高温高压微反应平台_V1 → 纯化工作站_纯化工作站_V1 → 超声清洗机_超声分散仪_V1 → 烘干机_烘干机_V1 → 管式炉_科晶_处理_V4 → 回收站_废液工作站303
