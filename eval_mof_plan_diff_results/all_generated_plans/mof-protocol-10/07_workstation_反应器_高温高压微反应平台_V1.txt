--------------------------------------------------------------------------------
MESSAGE #7 [workstation_反应器_高温高压微反应平台_V1]
--------------------------------------------------------------------------------
一级模块：反应器
二级子工作站：高温高压微反应平台_V1
功能动作参数块：

  - 三级功能：反应釜微反应

    - 适用容器：
      - 10ml耐压反应管（最多16个，默认4个，可分配，单次最多夹取16个）

    - 四级动作：

      - 动作：开盖
        参数：
          - 无
          - 备注：开启20 mL耐压反应管所在反应釜盖，准备放置MOF合成及Pt掺杂还原反应管。

      - 动作：放置柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：将装有前驱体溶液的20 mL耐压反应管放入反应釜，用于130°C溶剂热合成及后续Pt掺杂和还原反应。

      - 动作：关盖
        参数：
          - 无
          - 备注：关闭反应釜盖，确保密封，满足高温高压反应条件。

      - 动作：气密性检测
        参数：
          - 流量计流速：200
          - 时间：10
          - 压力值：1
          - 备注：检测反应釜密封性，确保130°C、90°C及110°C反应过程安全。

      - 动作：气体置换
        参数：
          - 气体置换次数：1
          - 压力：0.5
          - 流量计流速：200
          - 用于置换的气体：N2
          - 气体置换最后一次的CO2压力值：0
          - 时间：0.5
          - 备注：反应前对反应釜内部进行氮气置换，保障反应环境无氧。

      - 动作：启动
        参数：
          - 温度：130
          - 搅拌速度档位：3
          - 时间：1440
          - 开盖温度：25
          - 反应压力：0.5
          - 备注：启动MOF-BCP溶剂热合成反应，130°C反应24小时，密封反应。

      - 动作：开盖前气体置换
        参数：
          - 无
          - 备注：MOF合成反应结束后，反应釜内进行氮气置换，便于安全开盖。

      - 动作：开盖
        参数：
          - 无
          - 备注：反应结束后开启反应釜盖，取出MOF产物反应管进行后续洗涤。

      - 动作：拿取柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：取出完成溶剂热合成的MOF反应管，进行洗涤和干燥处理。

      - 动作：关盖
        参数：
          - 无
          - 备注：反应结束后关闭反应釜盖，准备下一步Pt掺杂反应。

  - 三级功能：微反应

    - 适用容器：
      - 无

    - 四级动作：

      - 动作：开盖
        参数：
          - 无
          - 备注：开启高温高压微反应平台反应器盖，准备放置反应管进行Pt掺杂及还原反应。

      - 动作：放置柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：将含有干燥MOF-BCP与K2PtCl4水溶液的反应管放入反应器，进行90°C Pt掺杂反应。

      - 动作：关盖
        参数：
          - 无
          - 备注：关闭反应器盖，确保密封，满足Pt掺杂反应条件。

      - 动作：气密性检测
        参数：
          - 流量计流速：200
          - 时间：10
          - 压力值：1
          - 备注：检测反应器密封性，确保Pt掺杂反应安全。

      - 动作：气体置换
        参数：
          - 气体置换次数：1
          - 压力：0.5
          - 流量计流速：200
          - 用于置换的气体：N2
          - 气体置换最后一次的CO2压力值：0
          - 时间：0.5
          - 备注：反应前对反应器内部进行氮气置换，保障Pt掺杂反应环境。

      - 动作：启动
        参数：
          - 温度：90
          - 搅拌速度档位：3
          - 时间：480
          - 开盖温度：25
          - 反应压力：0.5
          - 备注：启动Pt掺杂反应，90°C反应8小时。

      - 动作：开盖前气体置换
        参数：
          - 无
          - 备注：Pt掺杂反应结束后，反应器内进行氮气置换，便于安全开盖。

      - 动作：开盖
        参数：
          - 无
          - 备注：开启反应器盖，取出Pt掺杂产物，准备进行还原反应。

      - 动作：拿取柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：取出Pt掺杂后的MOF反应管，进行还原反应前的处理。
