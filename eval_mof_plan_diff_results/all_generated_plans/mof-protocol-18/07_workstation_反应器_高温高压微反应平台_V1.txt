--------------------------------------------------------------------------------
MESSAGE #7 [workstation_反应器_高温高压微反应平台_V1]
--------------------------------------------------------------------------------
一级模块：反应器
二级子工作站：高温高压微反应平台_V1
功能动作参数块：

  - 三级功能：反应釜微反应

    - 适用容器：
      - 10ml耐压反应管（最多16个，默认4个，可分配，单次最多夹取16个）

    - 四级动作：

      - 动作：开盖
        参数：
          - 无
          - 备注：开启10 mL耐压反应管反应釜盖，准备放置反应管，用于MOF 1溶剂热结晶反应。

      - 动作：放置柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：将装有前驱体溶液的10 mL耐压反应管放入反应釜，进行溶剂热结晶反应。

      - 动作：关盖
        参数：
          - 无
          - 备注：关闭反应釜盖，确保密封，满足100 °C溶剂热反应条件。

      - 动作：气密性检测
        参数：
          - 流量计流速：200
          - 时间：10
          - 压力值：1
          - 备注：检测反应釜密封性，确保溶剂热反应安全稳定。

      - 动作：气体置换
        参数：
          - 气体置换次数：1
          - 压力：0.5
          - 流量计流速：200
          - 用于置换的气体：N2
          - 气体置换最后一次的CO2压力值：0
          - 时间：0.5
          - 备注：对反应釜内部进行氮气置换，保障反应环境纯净。

      - 动作：启动
        参数：
          - 温度：100
          - 搅拌速度档位：3
          - 时间：1440
          - 开盖温度：25
          - 反应压力：常压
          - 备注：启动溶剂热结晶反应，100 °C，24小时，搅拌速度中档，反应压力常压。

      - 动作：开盖前气体置换
        参数：
          - 无
          - 备注：反应结束前对反应釜进行氮气置换，便于安全开盖和取出反应管。

      - 动作：开盖
        参数：
          - 无
          - 备注：再次开启反应釜盖，准备取出反应管，进行后续纯化处理。

      - 动作：拿取柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：取出完成溶剂热结晶反应的反应管，转入纯化工作站进行离心和洗涤。
