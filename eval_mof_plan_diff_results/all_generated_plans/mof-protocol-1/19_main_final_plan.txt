平台可执行实验流程（修订版）

1. 参考合成条件

- 试剂：Zn(NO₃)₂·6H₂O、terephthalic acid（对苯二甲酸）、2-methylimidazole（2-甲基咪唑）、DMF、甲醇、乙醇、调节剂（文献未提供具体名称）、惰性气体
- 配比/体积：MOF-5：Zn(NO₃)₂·6H₂O 1.0 g，terephthalic acid 1.5 g，5 mL DMF；ZIF-8：Zn(NO₃)₂·6H₂O 1.0 g，2-methylimidazole 2.0 g，甲醇体积文献未提供，需平台默认参数
- 反应条件：搅拌（MOF-5：20 min，文献未提供转速，ZIF-8：600 rpm，1 h），超声30 min（MOF-5），惰性气氛，结晶120°C，24 h（Teflon内衬高压釜）
- 后处理条件：自然冷却，过滤收集，DMF与乙醇交替洗涤3次（MOF-5）；甲醇洗涤2次（ZIF-8）；离心条件文献未提供，需平台默认参数；干燥120°C，12 h（MOF-5）；50°C，6 h（机械法）；活化120–150°C，12 h（真空）或40°C，1000 psi，2 h（超临界CO₂）
- 最终分散条件：文献未提供，需平台默认参数

2. 平台适配前提

- 机械法合成涉及球磨机，平台当前无自动球磨机接口，仅溶剂热法可全流程自动化。
- 微波辅助法不在当前用户需求范围，平台不做微波替代。
- 活化步骤需区分真空加热与超临界CO₂，平台仅支持真空加热（真空箱_自研真空仓_V1），不支持超临界CO₂活化。
- 洗涤体积、离心转速、分散体积等文献未提供，需平台默认参数。
- 结晶反应需用Teflon内衬高压釜，平台以“反应器_高温高压微反应平台_V1”兼容的高压反应管为标准。
- 所有操作需在惰性气氛下进行，平台需保证反应器密封及气氛管理。

3. 标准流程链

303物料站 → 单通道固体称量_v1 → 移液平台1ml_V1 → 常温磁力搅拌工作站_V1 → 超声分散仪_V1 → 反应器_高温高压微反应平台_V1 → 纯化工作站_V1 → 超声分散仪_V1 → 纯化工作站_V1 → 超声分散仪_V1 → 纯化工作站_V1 → 烘干机_V1 → 自研真空仓_V1 → 废液工作站303
