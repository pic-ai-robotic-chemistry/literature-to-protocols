平台可执行实验流程（修订版）

1. 参考合成条件

* 试剂及配比严格按文献步骤执行，具体见文献解析与平台适配规划。
* 关键反应条件：H2L1合成微波加热200 °C 2小时（平台用高温高压微反应平台替代）；H2L2合成室温搅拌过夜；MOF二次生长95/75/80 °C，定时更换溶液。
* 洗涤、离心、分散、消解等步骤体积、次数、条件均按文献，缺失部分标注“文献未提供，需平台默认参数”。
* 具体容器方案：4 mL进样瓶、10 mL耐压反应管、XRD基底片、液相54孔板等，按每个目标MOF体系独立分配。

2. 平台适配前提

* 微波加热步骤用“反应器_高温高压微反应平台_V1”替代，参数200 °C、2小时。
* 柱层析、减压浓缩、真空干燥等需人工或平台外部处理。
* α-MUF-9、α-MUF-10主晶格合成条件文献未提供，需平台默认参数。
* 洗涤/分散体积未给出，需平台默认参数。
* 容器、开盖/关盖、分装、并行等信息严格按orchestrator分步流程执行。
* 电化学相关内容不参与本流程。

物料站物料拿取 → 固体进样器固体进样 → 液体进样站开盖 → 液体进样站加液 → 液体进样站关盖-离心管 → 反应器高温高压微反应 → 反应器高温高压微反应（取出） → 纯化工作站纯化离心 → 纯化工作站容器拿放流程 → 超声清洗机超声清洗_双臂 → 液体进样站开盖 → 液体进样站加液 → 磁力搅拌加热磁力搅拌全流程 → 纯化工作站纯化离心流程_双臂 → 超声清洗机超声清洗_双臂 → 液体进样站开盖 → 液体进样站加液_物料绑定（二次生长溶液） → 磁力搅拌开始加热搅拌 → 纯化工作站离心纯化拿取流程 → 超声清洗机超声清洗_双臂 → 液体进样站开盖 → 液体进样站加液（洗涤/消解） → 超声清洗机超声清洗 → XRD工作站XRD滴液检测全流程 → 液相色谱仪液相分析 → 回收站处理废液_双臂
