--------------------------------------------------------------------------------
MESSAGE #7 [workstation_反应器_高温高压微反应平台_V1]
--------------------------------------------------------------------------------
一级模块：反应器
二级子工作站：高温高压微反应平台_V1
功能动作参数块：

  - 三级功能：微反应

    - 适用容器：
      - 无

    - 四级动作：

      - 动作：开盖
        参数：
          - 无
          - 备注：开启反应器盖，准备放置反应管及投料，涉及H₂L1、Zn(NO₃)₂·4H₂O、DBF、水等前驱体溶液的加样。

      - 动作：放置柱管
        参数：
          - 反应管编号：1,2
          - 备注：将装有反应混合物的反应管放入高温高压微反应平台，准备加热反应，适用于α‐MUF‐9前驱体溶解与晶体生长步骤。

      - 动作：关盖
        参数：
          - 无
          - 备注：关闭反应器盖，确保密封，准备进行85 °C或95 °C的溶剂热反应。

      - 动作：气密性检测
        参数：
          - 流量计流速：200
          - 时间：10
          - 压力值：1
          - 备注：检测反应器密封性，确保反应过程中无泄漏，保障实验安全。

      - 动作：气体置换
        参数：
          - 气体置换次数：1
          - 压力：0.5
          - 流量计流速：200
          - 用于置换的气体：N2
          - 气体置换最后一次的CO2压力值：0
          - 时间：0.5
          - 备注：对反应器内部进行氮气置换，排除空气，保障反应环境惰性。

      - 动作：启动
        参数：
          - 温度：85
          - 搅拌速度档位：3
          - 时间：360
          - 开盖温度：25
          - 反应压力：0.1
          - 备注：启动α‐MUF‐9前驱体溶解与晶体生长反应，温度85 °C，时间6小时，间歇搅拌保证混合均匀。

      - 动作：开盖前气体置换
        参数：
          - 无
          - 备注：反应结束前对反应器进行氮气置换，便于安全开盖和后续晶体收集。

      - 动作：拿取柱管
        参数：
          - 反应管编号：1,2
          - 备注：取出反应管，收集生成的α‐MUF‐9晶体，准备进行离心分离及二次生长。

  - 三级功能：反应釜微反应

    - 适用容器：
      - 10ml耐压反应管（最多16个，默认4个，可分配，单次最多夹取16个）

    - 四级动作：

      - 动作：开盖
        参数：
          - 无
          - 备注：开启反应釜盖，准备放置10 mL耐压反应管，用于二次生长反应步骤。

      - 动作：放置柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：将装有二次生长溶液和α‐MUF‐9晶体的10 mL耐压反应管放入反应釜，进行MUF-91、92、93及MUF-101的二次生长。

      - 动作：关盖
        参数：
          - 无
          - 备注：关闭反应釜盖，确保密封，准备进行75–95 °C的二次生长反应。

      - 动作：气密性检测
        参数：
          - 流量计流速：200
          - 时间：10
          - 压力值：1
          - 备注：检测反应釜密封性，确保二次生长反应过程安全无泄漏。

      - 动作：气体置换
        参数：
          - 气体置换次数：1
          - 压力：0.5
          - 流量计流速：200
          - 用于置换的气体：N2
          - 气体置换最后一次的CO2压力值：0
          - 时间：0.5
          - 备注：对反应釜内部进行氮气置换，排除空气，保障二次生长反应环境。

      - 动作：启动
        参数：
          - 温度：95
          - 搅拌速度档位：3
          - 时间：3600
          - 开盖温度：25
          - 反应压力：0.1
          - 备注：启动二次生长反应，温度75–95 °C，时间9–60小时，具体根据不同MUF调整，间歇搅拌保证晶体均匀生长。

      - 动作：开盖前气体置换
        参数：
          - 无
          - 备注：二次生长反应结束前对反应釜进行氮气置换，便于安全开盖和晶体收集。

      - 动作：开盖
        参数：
          - 无
          - 备注：开启反应釜盖，准备取出反应管，进行晶体收集及后续洗涤处理。

      - 动作：拿取柱管
        参数：
          - 反应管编号：1,2,3,4
          - 备注：取出二次生长反应管，收集MUF-91、92、93及MUF-101晶体，准备进行多轮洗涤和干燥活化。

      - 动作：关盖
        参数：
          - 无
          - 备注：实验结束后关闭反应釜盖，完成二次生长反应操作。
