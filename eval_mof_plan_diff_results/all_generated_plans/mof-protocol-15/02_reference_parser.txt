## 3. 关键实验步骤（仅文献明确报道）

### ZIF-UC-2合成流程
1. **前驱体溶解与混合**  
   - 称取：锌硝酸盐六水合物220 mg（0.74 mmol）、咪唑1188 mg（16.42 mmol）  
   - 溶剂：10 mL DMF  
   - 操作：将锌盐和咪唑溶解于DMF中，室温搅拌1小时  
   - 随后加入6-氯-5-氟苯并咪唑297.4 mg（1.74 mmol）  
2. **结晶**  
   - 将溶液转移至聚四氟乙烯衬里的高压釜中  
   - 条件：403 K，48小时  
3. **冷却与收集**  
   - 自然冷却至室温  
   - 通过过滤收集晶体  
4. **洗涤与溶剂置换**  
   - 用二氯甲烷反复洗涤晶体3次  
5. **干燥与活化**  
   - 真空烘箱中450 K干燥过夜，去除残留溶剂，激活样品

---

### ZIF-UC-3合成流程
1. **前驱体溶解与混合**  
   - 称取：咪唑60 mg（0.89 mmol）、5-氯-2-甲基苯并咪唑293 mg（1.76 mmol）、锌硝酸盐六水合物262 mg（0.88 mmol）  
   - 溶剂：3 mL DMF + 4 mL DEF  
   - 操作：室温搅拌1小时  
2. **调节剂添加**  
   - 加入0.25 mL 2.5 M NaOH溶液，促进有机配体脱质子化  
3. **结晶**  
   - 条件：383 K，5天  
4. **冷却与收集**  
   - 控制速率冷却至室温  
   - 过滤收集晶体  
5. **洗涤与干燥**  
   - 用二氯甲烷反复洗涤  
   - 真空烘箱450 K干燥过夜活化

---

### ZIF-UC-4和ZIF-UC-5合成流程（共用流程，部分差异见下）
1. **前驱体溶解与混合**  
   - ZIF-UC-4称取：咪唑120 mg（1.77 mmol）、5-氟苯并咪唑112 mg（0.82 mmol）、锌硝酸盐六水合物120 mg（0.40 mmol）  
   - ZIF-UC-5称取：文献未提供具体质量，但使用咪唑、5-氯苯并咪唑和锌硝酸盐六水合物  
   - 溶剂：8.3 mL DMF + 5.7 mL DEF  
   - 操作：室温搅拌1小时  
2. **调节剂添加**  
   - ZIF-UC-4加入0.52 mL 2.5 M NaOH  
   - ZIF-UC-5未添加NaOH  
3. **结晶**  
   - 条件：约363 K，5天  
4. **冷却与收集**  
   - 控制速率冷却  
   - 离心分离晶体  
5. **洗涤与干燥**  
   - 用二氯甲烷反复洗涤  
   - 真空烘箱450 K干燥过夜活化

### 文献实际使用的方法和用途
- **PXRD**：确认晶体结构和相纯度  
- **SCXRD**：确定单晶结构和配体位置

- **气体吸附测试（CO₂和N₂）**：评估气体吸附性能和循环稳定性
