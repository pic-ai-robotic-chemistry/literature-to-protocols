--------------------------------------------------------------------------------
MESSAGE #7 [workstation_反应器_高温高压微反应平台_V1]
--------------------------------------------------------------------------------
- 一级模块：反应器
- 二级子工作站：高温高压微反应平台_V1
- 功能动作参数块：

  - 三级功能：反应釜微反应

    - 适用容器：

      - 10ml耐压反应管（最多16个，默认4个，可分配，单次最多夹取16个）

    - 四级动作：

      - 动作：开盖
        参数：

        - 无
        - 备注：开启反应釜盖，准备放置4个10ml耐压反应管，反应管内装有对应ZIF前驱体溶液。

      - 动作：放置柱管
        参数：

        - 反应管编号：1,2,3,4
        - 备注：将编号1至4的10ml耐压反应管分别放入反应釜，分别对应ZIF-UC-2、ZIF-UC-3、ZIF-UC-4、ZIF-UC-5合成体系。

      - 动作：关盖
        参数：

        - 无
        - 备注：关闭反应釜盖，确保密封，准备进行溶剂热反应。

      - 动作：气密性检测
        参数：

        - 流量计流速：200
        - 时间：10
        - 压力值：1
        - 备注：检测反应釜密封性，确保反应过程中无泄漏，保障实验安全。

      - 动作：气体置换
        参数：

        - 气体置换次数：1
        - 压力：0.5
        - 流量计流速：200
        - 用于置换的气体：N2
        - 气体置换最后一次的CO2压力值：0
        - 时间：0.5
        - 备注：对反应釜内部进行氮气置换，排除空气，保障反应环境惰性。

      - 动作：启动
        参数：

        - 温度：130  # 403 K约等于130 ℃，对应ZIF-UC-2最高温度，兼容其他体系
        - 搅拌速度档位：3  # 默认中档搅拌速度，文献未明确具体搅拌速率
        - 时间：2880  # 48小时对应2880分钟，满足最长反应时间
        - 开盖温度：25  # 室温开盖
        - 反应压力：0.5  # 反应压力默认0.5 MPa，文献未明确具体压力
        - 备注：启动反应过程，温度设定为最高体系403 K对应温度130 ℃，时间覆盖最长反应48小时，适用于所有4个反应管。

      - 动作：开盖前气体置换
        参数：

        - 无
        - 备注：反应结束前对反应釜进行氮气置换，便于安全开盖，防止空气进入。

      - 动作：开盖
        参数：

        - 无
        - 备注：再次开启反应釜盖，准备取出4个反应管。

      - 动作：拿取柱管
        参数：

        - 反应管编号：1,2,3,4
        - 备注：取出编号1至4的10ml耐压反应管，含对应ZIF合成产物溶液。

      - 动作：关盖
        参数：

        - 无
        - 备注：实验结束后关闭反应釜盖，完成反应釜操作。
